# ADR 0009: Phase 7.1 functional boundaries

## Decision

Student identity and circulation decisions are database-authoritative. Stable member identifiers are generated by a private sequence; enrollment roll numbers belong to enrollment rows; search and report filters are applied by bounded security-definer read models; and policy exceptions are explicit typed settings.

## Consequences

Operators cannot edit generated identifiers or write circulation history directly. The UI can remain simple and search-first while the database preserves history, concurrency, authorization, and fail-closed policy behavior. Generated public types are release artifacts and must be regenerated from the final schema in CI.
